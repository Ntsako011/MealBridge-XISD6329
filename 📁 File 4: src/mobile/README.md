# MealBridge Mobile Application (Native Android/Kotlin)

## Project Overview
This is the official native Android app for the MealBridge system. It is developed using Kotlin and Android Studio. This mobile app shares a backend API with the website to ensure real-time synchronization of data.

## Key Features
- **Single Sign-On (SSO):** Login via Google using Firebase Auth.
- **User Request System:** Beneficiaries can easily submit food parcel requests.
- **Donation Portal:** Quick access to donate money via mobile payment, or submit goods delivery details.
- **Real-time Notifications:** Push notifications for food scheme dates and admin responses.
- **Volunteer Mobile Dashboard:** View assigned tasks and volunteer schedules.
- **AI Chatbot:** Integrated chatbot for instant query resolution.

## Technology Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose / XML
- **Database:** Firebase Firestore / MySQL (via API)
- **Networking:** Retrofit (Consuming REST APIs)
